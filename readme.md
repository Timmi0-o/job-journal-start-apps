# Job Journal — Start Apps

Скрипт для быстрого старта проекта с нуля

## Требования

Git · Node.js · npm · Docker (Docker Desktop должен быть запущен)

## Запуск

```bash
# macOS / Linux
./setup.sh

# Windows
setup.cmd

# или на любой ОС
node setup.mjs
```

После старта:

- API — http://localhost:7878/v1
- UI — http://localhost:3166
